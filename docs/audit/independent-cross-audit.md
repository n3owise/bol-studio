## Priority acceptance gaps found

1. **BOL-25, source-confirmed residual found and corrected during review:** active-job polling in `src/main.tsx` fetches the full project every 1.4 seconds; during export it retains only `exports`. Workspace summary polling now omits words, but export polling still repeatedly transfers all words and waveform. Add a metadata/export-only polling contract and retain full transcript fetching only when recognition completes. This was sent to the frontend agent and root. A follow-up source read shows summary-based transcription polling and exports-only polling now implemented; integrated response-size/browser verification remains the final acceptance check.
2. **BOL-17/BOL-06, resource acceptance gap found and partly corrected during review:** `server/render.ts` opens a raw video decoder for each visible video element plus primary. Disk quotas, 500-asset/element ceilings and 8192-pixel source dimensions do not themselves bound aggregate simultaneous decoder/frame memory or FFmpeg CPU. Width downscaling reduces individual frames, but many decoders still start during preload, including timeline-separated overlays. Add a configurable decoder/pixel workload preflight and a rejection test before process creation. This was sent to root. Follow-up source review confirms video workload preflight and timed decoder start/close were added. A subsequent image-memory gap (compressed high-resolution PNG preload outside the video budget) was sent to root; follow-up source now probes image dimensions and includes imageSpecs in the resource preflight. Integrated tests should verify both budgets reject before heavy decoding. No destructive stress test was attempted.
3. **BOL-04/BOL-26, evidence blocked:** no held-out reviewed translation/timing corpus was supplied. Decoder stubs prove engine/model/task routing, not translation, Hinglish accuracy, silence robustness or alignment quality. Model pins and hashes improve reproducibility, but no superiority claim is established. See model-reproducibility-and-evaluation.md.
4. **BOL-30, current documentation drift:** project-brain DATA_FLOW, SECURITY_CONSIDERATIONS and TESTING_STRATEGY still describe omitted save revisions, image-only export, absent quotas and only in-memory jobs from the baseline. Their dated audit prefaces make them valid historical records; treating them as present operational guidance remains unsafe. Add a current correction/link without rewriting original evidence. Inventory now needs a separate current snapshot.
5. **Runtime acceptance remains partial:** hosted Supabase refresh/JWKS rotation, real Linux/CUDA/Apple model decoding, TLS/proxy limits, retained-storage backup restore and mobile assistive technology have not been exercised. Local fixtures and unit tests must not be relabeled as those tests.
